# Prices Web Stress Tests Report

## Metodologi
Stress test dilakukan untuk mencari tau kapasitas maksimum yang bisa ditangani oleh prices web. Stress test dilakukan dengan komputer local dengan kondisi berikut:

- Komputer telah mengalami reboot
- Tidak ada disk limit
- RAM limit 8 GB

Stress test dilakukan dengan 3 stage dengan total 2 menit, yaitu:

1. **Load up stage (30 detik)**: meningkatkan virtual users (VU) ke jumlah yang diinginkan.
2. **Maintain stage (60 detik)**: mempertahankan jumlah VU.
3. **Load down stage (30 detik)**: menurunkan jumlah VU ke 0.
